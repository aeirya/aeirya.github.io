This selection highlights projects particularly relevant to software engineering and developer tooling. For a broader overview, see my [general portfolio](/portfolio/) or [complete project archive](/projects/).

## Selected work

### Compiler — C++

A compiler course project implemented in C++. It reflects my interest in programming languages and the tools that translate and process them.

**Areas:** C++ · compilers · programming languages

[Source code](https://github.com/aeirya/Compiler)

### Opfel — local LLM integration

A lightweight Python utility that redirects Apfeller plugin requests to **Ollama**, enabling an existing plugin workflow to use local language models.

**Areas:** Python · LLM integration · developer tooling

[Project overview](/projects/opfel/) · [Source code](https://github.com/aeirya/opfel)

### Open Journal Systems — plugins and infrastructure

Development and maintenance work around **Open Journal Systems (OJS)**, spanning plugin development, deployment tooling, and Docker-based infrastructure. This has involved working with existing codebases and operational workflows.

**Areas:** PHP · Docker · Linux · shell scripting · software maintenance

[Read the OJS case study](/projects/ojs/) · [Explore related repositories](https://github.com/ojs-inator)

### Gilaki language technologies — NLP tools

Ongoing work on computational tools for **Gilaki**, a low-resource Iranian language. A morphological inflection project explores finite-state methods and the use of generated data in language modeling experiments.

**Areas:** Python · computational morphology · low-resource NLP

[Project collection](/gilaki/) · [Morphology repository](https://github.com/aeirya/gilaki-inflection)
