A selection of projects that reflect my interests in **software engineering, programming languages, AI, and language technology**. For smaller experiments, coursework, and other projects, see the [complete project archive](/projects/).

## Selected work

### Open Journal Systems — plugins and infrastructure

Software development and maintenance work around [Open Journal Systems (OJS)](https://pkp.sfu.ca/software/ojs/), including plugins, operational tooling, and Docker-based infrastructure. This work combines backend development, automation, and keeping real systems running.

**Focus:** PHP · Docker · Linux · DevOps · automation

[Read the OJS case study](/projects/ojs/) · [Explore the repositories](https://github.com/ojs-inator)

### Compiler — C++

A compiler course project implemented in C++, reflecting my interest in programming languages, compilers, and systems-oriented software development.

**Focus:** C++ · compilers · language implementation

[View source code](https://github.com/aeirya/Compiler)

### Gilaki language technologies

Work on computational tools for **Gilaki**, a low-resource Iranian language. One ongoing project explores a morphological inflection model using finite-state methods, with a longer-term goal of using generated data for learned models.

**Focus:** natural language processing · morphology · low-resource languages

[Gilaki projects](/gilaki/) · [Morphology repository](https://github.com/aeirya/gilaki-inflection)

### Opfel — local LLM tooling

A small Python utility that connects Apfeller plugin requests to **Ollama**, making it possible to use local language models in that workflow.

**Focus:** Python · local LLMs · developer tooling

[Project overview](/projects/opfel/) · [View source code](https://github.com/aeirya/opfel)
