A small collection of my experiments, and tools I build:

* **[Opfel](/projects/opfel/)**
  A tiny Ollama-based bridge for Apfeller, built to keep local-AI workflows simple.
  [GitHub](https://github.com/aeirya/opfel)

* **[Whiteboard](https://github.com/wggb/whiteboard)**
  A simple browser-based whiteboard built with Paper.js, jQuery, and Bootstrap.

* **[Face Morphing](https://github.com/aeirya/face-morphing)**
  A small computer-vision project for morphing faces using Delaunay triangulation.

* **[TicTacToe](https://github.com/aeirya/TicTacToe)**
  A Java XO game server with support for multiple simultaneous matches and a simple CLI client.

* **[Tetris](https://github.com/aeirya/Tetris)**
  A Java implementation of Tetris game, built from scratch.
