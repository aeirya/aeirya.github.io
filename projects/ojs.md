## Overview

At **KMAN Publication**, I work on **KMANweb**, the tooling and infrastructure around [Open Journal Systems (OJS)](https://pkp.sfu.ca/software/ojs/) for hosting and managing academic journals.

## Open-source ecosystem

Our [**OJS-Inator GitHub organization**](https://github.com/ojs-inator) hosts **90+ repositories**, including many OJS plugins alongside deployment, migration, maintenance, and infrastructure tools.

## Evolution of the codebase

Many plugins were originally developed **before AI coding assistants**. We have since revisited and upgraded substantial parts of the codebase through **AI-assisted development**, with testing and review.

## Technology stack

**PHP, JavaScript, Python, Bash, SQL, Docker, Linux, Apache, and GitHub Actions**; plus services, APIs, server administration, and deployment automation.

## AI-agent workflow

I coordinate **task-focused coding and review agents** using shared instructions, repository-level `AGENTS.md` files, isolated workspaces and branches, and tracked issues/PRs. Cross-repository changes follow documented contracts, regression tests, and CI checks before integration.
